# VEX Engineering Framework

This directory contains the complete engineering framework for the VEX platform.

The framework defines:

- Engineering standards
- Architecture principles
- AI Operating System
- AI Runtime

The documentation is divided into four major areas.

---

## Entry points (read before everything else)

00_CONSTITUTION.md — highest authority, immutable

PROJECT_BRAIN.md — executive strategic context (PT-BR)

---

## Foundation

Project vision, product principles, engineering philosophy and technical standards.

Documents: 01_IDENTITY → 10_CODING_STANDARD

---

## Engineering

Architecture, database, APIs, security, testing, deployment and engineering processes. Includes the living documents (26-36: status, backlog, decisions, known issues, changelog, metrics, memory, glossary, playbook).

Documents: 11_BACKEND_GUIDELINES → 36_ENGINEERING_PLAYBOOK

---

## AI Operating System

Defines how AI should think, reason and execute engineering tasks.

Documents: 37_AI_STARTUP_PROTOCOL → 46_ENGINEERING_AUTOMATION

---

## AI Runtime

Defines how AI coordinates execution, tools, context, learning and autonomy.

Documents: 47_RUNTIME_ORCHESTRATOR → 52_AUTONOMOUS_ENGINEERING

---

## Entry Point

Start with:

26_INDEX.md (this directory has no separate INDEX.md — the master index is 26_INDEX.md)

Then follow the appropriate documentation according to the engineering task. For task-based routing use AI_NAVIGATION_GUIDE.md.
